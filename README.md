## À propos

Je suis une **femme transgenre** et développeuse indépendante. Je construis des outils utiles, souvent locaux, parfois auto-hébergés — parce que confier toute sa vie au cloud, c'est pratique jusqu'au jour où le cloud décide de faire une sieste.

Mon parcours m'appartient. Ici, je parle de qui je suis avec simplicité et fierté, sans que mon identité soit toute mon histoire : j'aime aussi résoudre des problèmes, en créer accidentellement, puis appeler ça « une soirée productive ».

```text
Identité       : femme transgenre 🏳️‍⚧️
Projet         : ProjetOmegaFR
Terrain de jeu : JavaScript · TypeScript · Python
Runtime        : Bun (Node.js, tu n'es pas personnellement visé)
Philosophie    : local-first · self-hosted · moins de dépendances, moins de drames
État           : techniquement en ligne
```
